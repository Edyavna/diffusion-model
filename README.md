# Диффузионная модель MNIST по Lecture_6_full.ipynb

## Готовый ноутбук для Google Colab

Файл `MNIST_Diffusion_Colab.ipynb` содержит определения модели, обучение, графики,
генерацию и скачивание результатов. U-Net автоматически скачивается с закреплённой
версии NVIDIA EDM с проверкой SHA-256; сопутствующие сведения сохраняются в `vendor/`.
Внешние `.py` файлы вручную загружать в Colab не нужно. Нужен доступ к GitHub.

1. Открой https://colab.research.google.com/ .
2. Выбери **Файл → Загрузить блокнот** и загрузи этот `.ipynb`.
3. В **Среда выполнения → Сменить среду выполнения** выбери GPU.
4. Запускай ячейки сверху вниз. Все настройки объяснены внутри ноутбука.

По умолчанию выполняется 6 эпох условного обучения; для первого знакомства
можно выбрать 1 эпоху. Опционально включается сохранение на Google Drive.
Ноутбук проверяется локально на искусственных данных в двух отдельных ядрах:
условная и безусловная модель, сохранение/загрузка, генерация и ZIP с исходниками.
Отчёт — `COLAB_CHECK.json`. Облачный Colab, CUDA, реальный Drive и полное обучение
на MNIST в эту проверку не входят.

`build_colab_notebook.py` пересобирает ноутбук из локального скрипта и vendor.
`check_colab_notebook.py` выполняет описанную проверку; для неё нужны
`nbformat`, `nbclient`, `ipykernel`, `matplotlib`, `tqdm`.

## Локальный Python-скрипт

Готовый скрипт на PyTorch: `DhariwalUNet` из NVIDIA EDM, обёртка `EDMPrecond`,
взвешенный denoising loss, метод Эйлера для ОДУ/СДУ, условная генерация и CFG.
Это реализация на уровне пикселей, а не latent diffusion и не Stable Diffusion.

Проверено 24 октября 2026 года: Windows, Python 3.12, CPU-сборки PyTorch и
torchvision (точные версии в `requirements-tested.txt`). Синтаксическая проверка,
`smoke-test` обеих моделей и все 4 автоматических теста прошли. Проверены также
одна эпоха на искусственных данных, вычисление тестового loss, PNG и загрузка
checkpoint. Полное обучение на MNIST, качество полученных цифр и CUDA не
проверялись. Обученных весов MNIST в поставке нет.

## Запуск в PowerShell

Все команды ниже выполняются из папки проекта:

```powershell
Set-Location 'C:\projects\diffusion-model'
```

В этой папке уже подготовлено окружение `.venv` с CPU-сборкой PyTorch. Активация
не обязательна: команды напрямую вызывают Python из окружения.

На другом компьютере создайте окружение и установите зависимости:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

`venv` изолирует библиотеки проекта. `python -m pip` устанавливает их именно
для указанного интерпретатора. Последняя команда добавляет остальные зависимости;
уже установленные совместимые версии torch/torchvision сохраняются.

Для NVIDIA GPU нужна CUDA-сборка PyTorch и совместимый драйвер. Подберите команду
для вашей системы в официальном установщике: https://pytorch.org/get-started/locally/ .
Подготовленная здесь CPU-сборка не сможет использовать GPU даже при наличии видеокарты.

### 1. Проверить работоспособность

```powershell
.\.venv\Scripts\python.exe diffusion_mnist.py smoke-test --device cpu
.\.venv\Scripts\python.exe -m unittest -v test_diffusion.py
```

`smoke-test` выполняет по одному шагу оптимизации на искусственных изображениях
для обеих моделей, проверяет градиенты, генерацию ОДУ/СДУ, CFG, сохранение и
загрузку `.pth`. MNIST не скачивается. Это проверка вычислений, а не обучение
распознаваемым цифрам. Ожидается завершение с `all smoke checks passed`.

### 2. Обучить условную модель

```powershell
.\.venv\Scripts\python.exe diffusion_mnist.py train --conditional --epochs 6 --output runs/conditional
```

- `train` — начать обучение с нуля.
- `--conditional` — учитывать метку цифры; используется 11 классов, где 10 означает отсутствие условия.
- `--epochs 6` — шесть проходов по обучающей выборке.
- `--output` — папка результатов; для нового запуска выбирайте новую папку.
- По умолчанию устройство выбирается автоматически: доступная CUDA, иначе CPU.

При первом обучении скачивается MNIST в `data/`. Безусловная модель запускается
той же командой без `--conditional`:

```powershell
.\.venv\Scripts\python.exe diffusion_mnist.py train --epochs 6 --output runs/unconditional
```

Значения по умолчанию взяты из ноутбука: batch size 256, Adam, learning rate
`3e-4`, изображения `16×16`, 32 базовых канала U-Net, множители `[1,2,3,4]`.
На CPU обучение может быть длительным. Для уменьшения нагрузки используйте
`--batch-size 32`; количество шагов на эпоху при этом увеличится.

### 3. Сгенерировать цифры 0–9

```powershell
.\.venv\Scripts\python.exe diffusion_mnist.py sample --checkpoint runs/conditional/best.pth --cfg 2 --output samples.png
```

По умолчанию сохраняется сетка из 40 картинок: в каждой строке классы 0,1,...,9.
Рядом создаётся `samples.json` с метками и параметрами генерации.

Для генерации только семёрок:

```powershell
.\.venv\Scripts\python.exe diffusion_mnist.py sample --checkpoint runs/conditional/best.pth --digit 7 --count 40 --cfg 2 --output sevens.png
```

`--cfg 0` означает обычную условную генерацию. Увеличение CFG усиливает влияние
класса, но не гарантирует улучшение изображения и может снижать разнообразие.
Для фиксированных весов и seed шум воспроизводится; побитовая одинаковость
между разными устройствами и версиями библиотек не гарантируется.

Другие варианты:

```powershell
# Обычная безусловная модель
.\.venv\Scripts\python.exe diffusion_mnist.py sample --checkpoint runs/unconditional/best.pth --output unconditional.png

# Условная сеть без указания класса: специальный класс 10
.\.venv\Scripts\python.exe diffusion_mnist.py sample --checkpoint runs/conditional/best.pth --unconditional --output no_condition.png

# Стохастический обратный процесс вместо детерминированного
.\.venv\Scripts\python.exe diffusion_mnist.py sample --checkpoint runs/conditional/best.pth --digit 7 --stochastic --output stochastic.png

# Все параметры генерации
.\.venv\Scripts\python.exe diffusion_mnist.py sample --help
```

## Результаты обучения

В папке запуска появятся:

| Файл | Содержимое |
|---|---|
| `last.pth` | Последние веса, конфигурация модели, номер эпохи, метрики, состояние Adam |
| `best.pth` | Веса эпохи с минимальным тестовым denoising loss и конфигурация |
| `config.json` | Параметры запуска, sigma_data и версия PyTorch |
| `metrics.csv` | Средняя ошибка обучения и тестовая ошибка по эпохам |
| `epoch_001.png` и далее | Примеры генерации после каждой эпохи |

`.pth` — checkpoint PyTorch: словарь тензоров и метаданных, а не ONNX и не
сериализованный объект всей нейросети. Загрузка создаёт архитектуру из
конфигурации и вызывает `load_state_dict`, используя `torch.load(weights_only=True)`.
Оптимизатор сохраняется для возможного продолжения обучения в дальнейшем;
команды resume в этом скрипте нет.

Тестовый loss считается на всём тестовом наборе с фиксированным генератором шума.
При условной модели он оценивает восстановление с настоящими метками, без их
случайной замены на 10. Это не accuracy классификации и не FID. `best.pth`
выбирается по тестовому набору для учебного сценария; для независимой итоговой
оценки нужен отдельный validation split и нетронутый test split.

## Как читать реализацию

1. `EDMPrecond` — создаёт U-Net, рассчитывает `c_in`, `c_skip`, `c_out`, `c_noise`.
2. `edm_loss` — выбирает lognormal sigma, добавляет шум и сравнивает денойзер с оригиналом.
3. `train` — обновляет веса, вызывает тестирование и сохраняет результаты.
4. `get_timesteps` — строит убывающие уровни sigma с rho=7 и финальным нулём.
5. `sample_euler` — начинает с шума и пошагово формирует изображение.
6. `generate` — загружает checkpoint, выбирает метки и сохраняет PNG.

В обозначениях ноутбука:

```text
Обучение:
x_clean → x_clean + sigma * noise → EDMPrecond(U-Net) → weighted MSE с x_clean

Генерация:
N(0, sigma_max²) → шаг Эйлера → меньший sigma → ... → sigma=0 → изображение
```

На каждом шаге генерации U-Net получает положительный sigma. Ноль — только
конечная точка интегрирования, поэтому `log(0)` и деления на ноль нет.
Скорость `(x-D)/sigma` умножается на отрицательный шаг sigma. Для СДУ скорость
удваивается и добавляется шум `sqrt(2*sigma*abs(delta_sigma))*epsilon`.

## Исправления относительно ноутбука

- Для тестовых картинок используется `transform`, а не ошибочный `target_transform`.
- `test_dataloader` действительно используется для вычисления ошибки.
- Удалены неработающие параметры EMA; усреднение весов не заявляется и не выполняется.
- Нет жёстких `.cuda()`: устройство выбирается явно или автоматически.
- Метки при classifier-free dropout не изменяются на месте.
- Нет повторных определений sampler; знак шага и скорости согласован в одной реализации.
- Визуализация не использует нормализацию по максимуму пакета; для PNG применяется
  обратное преобразование из `[-1,1]` и clamp. Эта обработка не влияет на генерацию.
- Добавлено сохранение и восстановление весов, отсутствовавшее в ноутбуке.

Скрипт не обещает совпадения результатов с сохранёнными картинками ноутбука:
обучение случайное, а версия исходников EDM, использованная автором, не закреплена
в самом ноутбуке. Здесь версия NVIDIA зафиксирована в `vendor/SOURCE.md`.
